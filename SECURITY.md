# Security policy

Vulnerabilities in Headscale or Headplane themselves: report them to
[juanfont/headscale](https://github.com/juanfont/headscale/security) or
[tale/headplane](https://github.com/tale/headplane/security).

Vulnerabilities in this template (Compose file, routing, helper containers,
scripts): use GitHub's **Report a vulnerability** button on this repository
(private vulnerability reporting) rather than a public issue. Include the
template version, Dokploy version and steps to reproduce.

See the README's [Security](README.md#security) section for the design
(isolation, admin helper, request filtering, secrets).
